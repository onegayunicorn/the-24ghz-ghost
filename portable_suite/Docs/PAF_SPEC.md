# PAF Specification — Implemented Subset

## Mandatory folders
- `App/`      — binaries and runtime
- `Data/`     — user data, settings, logs
- `AppInfo/`  — metadata

## Mandatory: AppInfo/appinfo.ini [Details]
| Field | Required |
|---|---|
| Name | \u2705 |
| Version | \u2705 (X.Y.Z recommended) |
| Publisher | \u2705 |
| Category | \u2705 (from standard list) |
| Description | \u2705 |
| Executable | \u2705 (relative path, forward slashes) |

## Standard categories
Accessibility, Developer, Education, Games, Graphics, Internet,
Multimedia, Office, Security, System, Utilities, Other
